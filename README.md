# 🌍 Tourism Website

A modern and responsive tourism website designed to showcase travel destinations, events, accommodations, and tourism services through an interactive and user-friendly interface.

This project was developed using **HTML5** and **CSS3** to strengthen front-end web development skills and create a visually appealing travel platform experience.

---

🚀 Live Demo
https://sainagesh791.github.io/Tourism-Website/

# Features

## 🏠 Home Page

* Attractive landing page
* Featured travel destinations
* Tourism highlights and promotions

## 📖 About Us

* Information about the tourism service
* Mission and travel experience details

## 🎉 Events Section

* Special tourism events
* Seasonal offers and travel promotions

## 🏨 Accommodations

* Hotel and stay information
* Travel package details
* Booking-style interface design

## 📧 Contact Page

* User inquiry section
* Contact information layout

## 🔐 Login Form

* User authentication interface
* Styled login page design

## 📱 Responsive Design

* Mobile-friendly layout
* Clean navigation system
* Optimized UI structure
