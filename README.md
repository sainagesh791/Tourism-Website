# Tourism Website

A comprehensive tourism website showcasing travel destinations, events, accommodations, and travel packages with a user-friendly interface.

## Features

- 🏠 **Home Page** - Featured destinations and attractions
- 📖 **About Us** - Information about the tourism service
- 🎉 **Events** - Special events and promotions
- 🏨 **Accommodations** - Stay options and bookings
- 📧 **Contact** - Get in touch with inquiries
- 🔐 **User Login** - Secure user authentication
